# Mr Doran Clicker

A small browser clicker game using the supplied Mr Doran photo.

## Run it locally
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, `game.js`, and the `assets` folder together.
3. Open `index.html` in a web browser.

## Publish it on GitHub Pages
1. Create a new repository on GitHub (for example, `mr-doran-clicker`).
2. Upload all files and the `assets` folder to the repository's main branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then press **Save**.
6. Wait for GitHub Pages to publish the site. The Pages screen will show its public URL.

No build tools or dependencies are required.
